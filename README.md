# Визуальный Т‑Банк

Интерфейс-концепт главного экрана банковского приложения в эстетике Т‑Банка.

Это **только визуальное демо** с примерными данными: без реальных платежей, без сбора логинов и без связи с настоящим банком.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```
